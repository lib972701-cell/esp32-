# 视觉串口接线建议（2026-10-14）

## 最新重新选脚：TX=IO6，RX=IO16，IO7保留

| ESP32 | 方向 | MaixCAM2侧面UART4 |
|---|---|---|
| IO6/P1-3，UART2 TX | → | A22，UART4 RX |
| IO16/P1-6，UART2 RX | ← | A21，UART4 TX |
| GND/P1-24 | 共地 | GND |

保留IO7的原IMU INT接线。IO16排针位置与RGB LCD/板载摄像头复用已按手册核对，当前代码未使用；使用前确认这些外设未接且IO16无其他外接占用。配置及Kconfig默认TX6/RX16已同步，驱动拒绝使用IO7；业务UART仍禁用，未烧录，接线确认后才启用。下方6/7和旧B0/B1表为历史，不再适用。

## 接线更正：IO7保留，原视觉RX建议撤回

用户指出IO7已接IMU的INT。当前集成代码未把GPIO7绑定为INT输入/ISR，MPU6050通过I2C读取INT_STATUS并按8ms周期轮询，但软件未用该脚不等于物理空闲。因此保留用户原INT接线，不再把Maix A21/TX接到IO7。下方IO7及6/7组合均为已撤回建议，视觉RX需另选并核实空闲脚后更新；ESP UART目前仍禁用，尚未写入/烧录6/7映射。Maix UART4 A21/A22配置不受此更正影响。

## 最新用户选择：MaixCAM2侧面六针UART4

用户随后指定侧面1.25mm六针接口，Maix视觉已改为UART4：ESP IO6/P1-3 TX→Maix A22/RX；ESP IO7/P1-4 RX←Maix A21/TX；P1-24 GND共地。只接三线，不接该接口5V/I2C，两板各自供电。Maix为/dev/ttyS4、A21/A22，启动前释放本进程默认Maix监听。42项本地测试通过；用户重新连接后已更新正式应用，3秒IDLE测试exit0确认UART4打开，恢复自启后进程持有/dev/ttyS4且持续IDLE。尚未双板通信实测，ESP配置仍禁用。下方B0/B1为此前未采用建议。

这是根据手册、官方引脚图和当前源码提出的接线建议，尚未由用户确认完成接线。软件UART保持禁用；本轮未修改固件GPIO或MaixCAM2设置、未烧录。

使用前确认ESP32未接RGB屏/板载摄像头，IO6/IO7及MaixCAM2 B0/B1未接其他外设。

| ESP32 DNESP32S3 V1.0 | 方向 | MaixCAM2 |
|---|---|---|
| P1-3，IO6，计划UART2 TX | → | B1，丝印U2R，UART2 RX |
| P1-4，IO7，计划UART2 RX | ← | B0，丝印U2T，UART2 TX |
| P1-24，GND | 共地 | 排针GND |

先断开两板电源和USB，接上三根线，再恢复各自供电。只连接TX/RX/GND，不互接5V或3V3，不用ESP32的3V3给MaixCAM2供电。3.3V TTL、115200、8N1、无流控。按丝印辨认，不能因翻转板子而只按左右/第几个针判断。

ESP32 GPIO6/7在手册物理第14页确认对应P1-3/4；物理第11页显示与RGB LCD/摄像头复用，当前源码无占用，但外部占用仍需实物确认。DTU继续GPIO17/18、IMU继续4/5、音频和USB不改。

MaixCAM2官方[引脚图](https://wiki.sipeed.com/hardware/assets/maixcam/maixcam2_pins.jpg)及[UART文档](https://wiki.sipeed.com/maixpy/doc/zh/peripheral/uart.html)确认B0=UART2_TX、B1=UART2_RX、设备/dev/ttyS2；[PINMAP文档](https://wiki.sipeed.com/maixpy/doc/zh/peripheral/pinmap.html)明确3.3V IO。选2.54mm排针U2T/U2R，不用日志U0T/U0R或默认6pin UART4。

后续软件配置应为：ESP32 CONFIG_VISION_UART_ENABLE=y、TX=6、RX=7；Maix UART_DEVICE=/dev/ttyS2、UART_PINMAP={"B0":"UART2_TX","B1":"UART2_RX"}。这是待接线确认后实施的配置，本轮没有写入产品配置。

本轮device check实际返回Connection closed，未能做Maix运行时串口占用检查，不能把官方功能映射当作实际打开端口成功。接线后仍需配置、构建、烧录及双板SYNC/ACK与按键实测。
