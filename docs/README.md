## 资料分类

```text
docs/
├─ guides/          使用、接线与调试
├─ architecture/    当前代码结构与系统流程
├─ design/          设计说明（历史设计明确标注日期）
├─ plans/           开发计划记录
├─ images/          手册截图、PNG/SVG图示
├─ verification/    人可读的测试与审查报告
└─ history/         旧版说明及整理前文档
```

`images/system_architecture.*`、`images/boot_mail_flow.*` 是2026-10-12单邮件版本图示；当前集成流程以 `architecture/` 为准。旧说明完整保留在 `history/`，不覆盖当前源码与最新实测。第三方组件自带README/LICENSE随依赖保留。
