# KEY0 云端语音接入设计（2026-10-14按用户范围修订）

只增加Wi-Fi云端语音和KEY0控制，不引入显示、摄像头、字体、LVGL、图像或模型资源。复用小智2.0.3的服务发现、激活、MQTT/UDP与WebSocket协议，以及ES8388、Opus、Wi-Fi配置组件。

短按KEY0释放后开启连续对话，长按2000ms停止录音与播放并关闭会话；消抖30ms，长按释放不触发短按，读失败解除武装，上电按住不触发。关闭及重新开启用代次隔离旧音频和已排队回调。

摔倒算法、配置业务、采样任务、事件及DTU邮件保留。30个保护原文件哈希不变。独立采样core1优先级8，云端初始化和语音任务core0。底层IMU新I2C适配保持原GPIO4/5、地址与超时，使用I2C1；音频及KEY0为GPIO41/42的I2C0。

保留原分区、NVS和旧配置，使用独立sdkconfig.cloud/build-cloud及IDF5.4。构建通过，固件0x1b5300字节，原0x1f0000应用分区剩余12%。完整宿主回归通过；未烧录或验证真实云端对话、按键与并发采样。
