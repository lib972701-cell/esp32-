# 视觉接入验证（2026-10-14）

## 本轮完成范围

基于当前sample_project新增外部MaixCAM2双模式接入：KEY1短按LIGHT、KEY2短按PERSON、长按2秒退出对应业务；KEY0保持对话入口，统一通过前台调度与视觉互斥。视觉先输出状态与UART0日志，不增加播报。摔倒检测独立持续运行。

UART2与GPIO为可配置接口，默认禁用/TX RX=-1。未烧录、未更新MaixCAM2设备配置、未完成UART接线或双板联调。本轮结果只证明源码、宿主行为和构建，不证明实际识别效果、硬件互斥或人体摔倒性能。

新增测试先暴露缺失功能；云端关闭后需新短按的场景首次断言失败，再修正状态机转绿。门控关闭确认函数及三键滤波也先运行缺失接口测试，再实现通过。最终日志没有新增C/C++编译警告；早期GPIO=-1在SDK宏内产生负移位警告，已通过先范围校验再查有效掩码修复。工具链仍有此前框架Git版本信息不可用的环境提示，最终构建退出0。

状态机场景包括：云端启动必须等待远端IDLE ACK、视觉启动必须等待云端停止、快速切换及对应长按退出、UART未配置保留KEY0、CRC/分包/超长/残包/非法字段与旧帧、断线/重启撤销、ACK三次重试/FAULT、人数语义/frame回绕、云端失败关闭后不自动重启。

8个原源码改动为CloudAI/board/board.cc、key0_driver.cc，CloudAI/control/application.cc/.h、cloud_ai.cc/.h、conversation_gate.h，以及main/main.c。原DTU传输、定位、TLS/SMTP、邮件业务、IMU驱动、摔倒算法/任务代码均未改。构建登记、默认配置、测试与文档另行增量更新，不纳入88个源码统计。
